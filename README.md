# 🚲 EasyBike - Peer-to-Peer Bike Rental Platform

EasyBike is a full-stack bike rental platform that connects bike owners and customers. 
Users can list their bikes for rental, customers can browse and book available bikes, and admins can manage bike approvals and bookings.

Built using **React, Spring Boot, MySQL, and Spring Security**.

---

## ✨ Features

### 👤 Customer

- User registration and authentication
- Browse approved bikes
- Search bikes by brand and model
- View complete bike details
- Book bikes with pickup and return dates
- View booking history
- Cancel bookings
- Register personal bikes for rental


### 🛡️ Admin

- Admin dashboard with platform statistics
- View pending bike registrations
- Approve or reject bike listings
- Manage customer bookings
- Track booking status and revenue
